## 🚀 Démarrage Rapide

### Installation

1. **Clonez le dépôt**
```bash
git clone https://github.com/lancineadamafofana-hash/developpeur-informatique.git
cd developpeur-informatique
```

2. **Ouvrez dans votre navigateur**
```bash
# Avec Python 3.7+
python -m http.server 8000

# Avec Python 2
python -m SimpleHTTPServer 8000
```

3. **Accédez à la plateforme**
```
http://localhost:8000
```

## 📝 Exemples de Code

### Exemple 1: Variables
```python
nom = "Alice"
age = 25
print(f"Je m'appelle {nom} et j'ai {age} ans")
```

### Exemple 2: Fonctions
```python
def additionner(a, b):
    return a + b

resultat = additionner(5, 3)
print(resultat)  # 8
```

### Exemple 3: Classes
```python
class Personne:
    def __init__(self, nom, age):
        self.nom = nom
        self.age = age
    
    def saluer(self):
        print(f"Bonjour, je suis {self.nom}")

personne = Personne("Bob", 30)
personne.saluer()
```
